# Vojtas Casino

Projekt kasyna za fikcyjne żetony.

- `index.html` zawiera strukturę strony.
- `style.css` zawiera proste style.
- `script.js` obsługuje grę i saldo początkowe 1000 żetonów.
- `Baza Atlas MongoDB` baza do operacji na danych użytkowników.

Otwórz `index.html` w przeglądarce, aby uruchomić projekt.
